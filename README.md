# YouRule
YouRule is a real-time game management platform that allows non-technical users to design and run custom physical games without writing a single line of code. Using a visual, block-based editor powered by Blockly, users drag and connect blocks to define game rules, scoring conditions, zones, and events. YouRule then processes those blocks, converts them into executable logic, and referees the game automatically in real time.

The platform is built to be highly flexible. Users can create games in virtually any shape or format they imagine, from simple zone-based scoring to complex multi-step sequences involving passes, contacts, and timed events. It is suitable for anyone who wants to design and run a fun, structured physical game, whether that is a teacher running an activity in a classroom, a coach designing a training drill, or an individual creating a custom sport from scratch.
